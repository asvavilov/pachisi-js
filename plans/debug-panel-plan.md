# Debug-панель для ручного тестирования

## Концепция

Добавить в `GamePanel.vue` отладочную секцию, которая позволяет:

1. **Задавать позиции фишек** — перетаскивать или выбирать ячейку для каждой фишки
2. **Задавать значения костей** — уже есть, но сделать более удобным
3. **Просматривать лог вычислений** — что и почему решила игровая логика

Панель должна быть свёрнута по умолчанию и открываться по кнопке "Debug".

---

## 1. Управление позициями фишек

### Вариант A: Выпадающие списки для каждой фишки (проще)

Для каждой из 16 фишек (4 игрока × 4 фишки) показывать:

- `[Игрок] [цвет] Фишка #[id]` → `<select>` со списком всех ячеек доски

**Плюсы:** Просто реализовать, не ломает существующий UI.
**Минусы:** Огромный список (68 + 4×8 + 4 = ~104 ячейки).

### Вариант B: Клик по ячейке в debug-режиме (сложнее)

Включается "режим редактирования" — клик по фишке выбирает её, клик по ячейке перемещает.

**Плюсы:** Интуитивно, наглядно.
**Минусы:** Требует изменений в MainBoard/CellBoard/ChipBoard.

### Вариант C: Текстовое поле с JSON (для продвинутых)

Одно большое текстовое поле, куда вставляется JSON вида:

```json
{
  "chips": {
    "0": { "cellType": "main", "cellIndex": 4 },
    "1": { "cellType": "base", "cellIndex": 0 },
    ...
  },
  "dice": [3, 5],
  "usedDice": [3],
  "bonusSteps": [20],
  "state": "WAIT_STEP"
}
```

**Плюсы:** Максимальная гибкость, можно сохранять/загружать сценарии.
**Минусы:** Требует знания структуры данных.

### Рекомендация: Вариант A + C

- Для быстрого доступа — выпадающие списки для каждой фишки (упрощённые: только тип доски + индекс)
- Для сложных сценариев — JSON-редактор с кнопкой "Применить"

## 3. Лог вычислений

Добавить в `gameStore` массив `debugLog: DebugEntry[]`, куда каждая функция пишет:

```typescript
interface DebugEntry {
  timestamp: number;
  function: string;
  message: string;
  data?: Record<string, unknown>;
}
```

Функции, которые должны логировать:

- `findTargetCellVariants()` — откуда, сколько шагов, какие варианты, почему rejected
- `canMoveChip()` — результат проверки
- `isCellBlocked()` / `isCellDisabled()` — какая ячейка, результат
- `moveChip()` — что переместили, захват, бонус
- `handleThreeDoubles()` — какая фишка отправлена на базу
- `selectFirstPlayer()` — результаты выбора

Лог отображается в панели как прокручиваемый список с цветовой кодировкой:

- 🟢 success/ход
- 🟡 warning/блок
- 🔴 error/отказ
- 🔵 info
