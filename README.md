# Pachisi (pachisi)

pachisi board game

## Правила игры (классический Ludo / Пачиси)

### Цель игры

Первым провести все четыре свои фишки из стартовой зоны по круговой доске в домашнюю зону.

### Участники

- 2–4 игрока.
- Каждый игрок имеет четыре фишки одного цвета (зелёный, жёлтый, красный, синий).

### Доска

- Круговая дорожка из 68 ячеек (включая безопасные ячейки).
- У каждого игрока есть стартовая зона (4 ячейки) и домашняя зона (4 ячейки).
- Безопасные ячейки (отмечены звёздочкой) защищают фишки от захвата.

### Ход игры

1. Игроки ходят по очереди по часовой стрелке.
2. В свой ход игрок бросает **два шестигранных кубика**.
3. Результаты кубиков можно использовать двумя способами:
   - **Суммарно**: переместить одну фишку на сумму выпавших очков.
   - **Раздельно**: переместить две разные фишки на количество шагов, равное значению каждого кубика соответственно.
4. Чтобы вывести фишку из стартовой зоны на стартовую ячейку главной доски, необходимо выбросить **6** на одном из кубиков (или дубль 6‑6). Если выпала 6, игрок может либо вывести новую фишку, либо двигать уже находящуюся на доске.
5. Если выпал **дубль** (одинаковые числа на обоих кубиках), игрок получает **дополнительный ход** после завершения текущего.
6. Если фишка попадает на ячейку, занятую фишкой противника, и эта ячейка **не является безопасной**, фишка противника возвращается в его стартовую зону.
7. Игрок **обязан сделать ход**, если у него есть хотя бы одна доступная фишка. Если ходов нет, ход переходит к следующему игроку автоматически.
8. Фишка считается завершившей путь, когда она попадает в домашнюю зону и занимает одну из четырёх конечных ячеек. Для точного входа в домашнюю ячейку требуется точное количество шагов. Если количество шагов превышает необходимое, фишка остаётся на месте.

### Конец игры

Побеждает игрок, который первым разместил все четыре фишки в своей домашней зоне.

```bash
yarn
# or
npm install
```
