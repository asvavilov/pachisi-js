## Правила игры

Подробное описание схемы доски для игры в Парчис (Parchis) с нюансами

1. Базы игроков
   Расположение: в четырёх углах доски (красный, синий, зелёный, жёлтый).
   Назначение: стартовая зона для фишек каждого игрока.
   Начальное расположение фишек: три фишки находятся на базе, одна — на выходе из базы.
   Цель: довести все фишки из базы до финиша (центрального поля).

2. Выход из базы (стартовая ячейка, часть общей дорожки)
   Расположение: непосредственно рядом с базой (первые ячейки цветной зоны — например, 39–42 для красного игрока).
   Является безопасной, за исключением, если осуществляется выход из базы.
   Правила выхода:
   - фишка выходит только при выпадении 5 очков на кости (или комбинации, дающей 5, например, 4+1);
   - если занята одной фишкой противника, то фишка противника сбивается;
   - выход возможен только если ячейка не занята другой своей фишкой.

3. Общая дорожка (крестообразная зона)
   Описание: центральная часть доски, где фишки движутся против часовой стрелки.
   Нумерация: ячейки пронумерованы (1–67), что помогает отслеживать прогресс.
   Безопасные ячейки: отмечены кругами на ячейках — здесь фишки нельзя «выбить» соперником.
   Движение:
   - движение против часовой стрелки;
   - можно выбирать в любом порядке к каким фишкам какие кости использовать для хода (сначала один кубик для одной фишки, потом второй для другой, либо оба кубика для одной фишки (сумма));
   - на одной ячейке может быть максимум две фишки одного цвета;
   - блок: две фишки одного цвета на одной ячейке создают блокаду, которую нельзя «перепрыгнуть».

4. Цветные дорожки к финишу
   Расположение: перед «домом» каждого игрока (прямые зоны по цвету игроков).
   Назначение: финальный отрезок пути перед попаданием в «дом».
   Особенности:
   - фишки могут войти сюда только после полного круга по общей дорожке;
   - вход на цветную дорожку — точное попадание (например, если до входа 3 ячейки, нужно выбросить 3 очка).

5. Финиш (центральные цветные места — «дома»)
   Цель игры: довести все фишки до своего «дома».
   Правила попадания:
   - только при точном совпадении очков с количеством ячеек до финиша (включая бонусные очки);
   - фишки других игроков не могут заходить на цветную дорожку соперника.

   Если очки позволяют как зайти на финиш, так и продолжить движение по кругу, то у пользователя появляется выбор.

6. Бонусы
   - за попадание фишки в «дом» — +10 очков (можно использовать для хода одной фишкой);
   - за выбивание фишки соперника — +20 очков (также используется для хода).

   Можно применять к любым фишкам, в любом порядке, аналогично применению кубиков.
   Можно использовать по отдельности, не плюсуются в какую-то единую сумму.
   Сбрасываются со следующим броском любого игрока (текущего при дополнительном ходе, или следующего при переходе хода).

7. Ключевые точки схемы
   Пересечение дорожек (центр доски): нейтральная зона.
   Вход на цветную дорожку: расположен после завершения круга по общей дорожке.
   Финальные ячейки: последние ячейки перед «домом» (например, 1–8 для жёлтого игрока).

8. Правила взаимодействия фишек
   Сбивание: если фишка приземляется на ячейку с фишкой противника, фишка соперника возвращается в базу, а сбившая фишка получает бонус (+20 очков).
   Безопасные зоны:
   - ячейка выхода игрока - безопасна только для него;
   - фишки на безопасных ячейках невозможно сбить;
   - если ячейка занята фишкой противника и она безопасная для него, то нельзя на нее встать.

   Блокады:
   - две фишки одного цвета на одной ячейке создают непреодолимую блокаду;
   - блокаду нельзя «перепрыгнуть», даже своей фишкой;
   - если фишки образуют блок, обязательный ход одной из фишек блока при выпадении 6.

9. Особые правила
   Дубль (одинаковые значения на костях):
   - даёт право на повторный ход;
   - при трёх любых дублях подряд — фишка, ближайшая к финишу, возвращается на базу.

   Выпадение 6:
   - обязательный дополнительный ход;
   - если все 4 фишки игрока на базе — фишки остаются на месте, делается дополнительный бросок.

   Отсутствие хода: если нет возможности передвинуть фишки согласно правилам, ход пропускается.

10. Порядок хода (ход - то что между бросками костей)
    Очередность: определяется броском кости в начале игры (меньшее значение — первый ход);
    Дальнейшее движение: игроки ходят по очереди против часовой стрелки.
    За ход нужно в любом порядке использовать все кости и бонусы, до тех пор пока возможны ходы.

11. Победа
    Условие победы: первый игрок, который приведёт все 4 фишки в свой «дом», выигрывает.
    Дополнительные места: остальные игроки продолжают борьбу за 2–4 места (если остаются одни ИИ, то игра завершается).

## Install the dependencies

```bash
yarn
# or
npm install
```

### Start the app in development mode (hot-code reloading, error reporting, etc.)

```bash
quasar dev
```

### Lint the files

```bash
yarn lint
# or
npm run lint
```

### Format the files

```bash
yarn format
# or
npm run format
```

### Build the app for production

```bash
quasar build
```
