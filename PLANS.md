> 2.2–2.3 — масштабный рефакторинг, рискованный перед релизом. Отложено на v2.

| #   | Задача                                                                                                                                                                                       |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2.2 | **Переход от OOP-классов к FP**. `Board`, `Cell`, `Chip`, `Player` — классы с мутабельным состоянием. AGENTS.md требует чистые функции и иммутабельность.                                    |
| 2.3 | **Бизнес-логика в stores**. `game.ts` содержит правила игры (валидация ходов, расчёт бонусов, определение победителя) — это должно быть в `src/lib/`. Stores должны делегировать вычисления. |

## 8. Следующие релизы

| #   | Идея                                                                                                                                                                                                                                                                                              |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 8.1 | **Мультиязычность (i18n)**: вынести строки из шаблонов, добавить `ru-RU` и другие локали. Сейчас — только русский, текст в шаблонах. При переходе на файлы локалей вернуть `@intlify/unplugin-vue-i18n`.                                                                                          |
| 8.2 | **Настройка состава 2–4 игроков**: экран выбора количества игроков, для каждого — человек/ИИ и цвет. Сейчас жёстко 1 человек + 3 ИИ.                                                                                                                                                              |
| 8.3 | **Уровни сложности ИИ** (лёгкий/обычный/сложный) и, возможно, доля случайных ходов.                                                                                                                                                                                                               |
| 8.5 | **TypeScript 7 — отложен**: `typescript@7` — нативный компилятор без JS-API, `vue-tsc` использует JS-API (`typescript/lib/tsc`). Обходной путь — алиас `typescript` на `@typescript/typescript6` (фактически TS6, без выигрыша). Вернуться, когда Volar поддержит нативный компилятор для `.vue`. |

> **Заметка (Windows/OneDrive):** проект лежит в папке OneDrive, и `npm install` периодически падает с `EBUSY` — OneDrive держит файлы в `node_modules`. Перед крупными апдейтами ставить OneDrive на паузу; в идеале вынести репозиторий из OneDrive или исключить `node_modules` из синхронизации.
