## 2. Архитектурные нарушения (AGENTS.md vs реальность)

| #   | Задача                                                                                                                                                                                                       | Детали |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| 2.1 | **`src/lib/` не должен зависеть от Vue**. `cell.ts` импортирует `reactive`, `chip.ts` импортирует `toRaw`. Нарушает принцип «чистая логика без Vue-зависимостей».                                            |
| 2.2 | **Переход от OOP-классов к FP**. `Board`, `Cell`, `Chip`, `Player` — классы с мутабельным состоянием. AGENTS.md требует чистые функции и иммутабельность. Масштабный рефакторинг — отложить на post-release. |
| 2.3 | **Бизнес-логика в stores**. `game.ts` содержит правила игры (валидация ходов, расчёт бонусов, определение победителя) — это должно быть в `src/lib/`. Stores должны делегировать вычисления.                 |
| 2.4 | **`chipIdCounter` — глобальное мутабельное состояние** (`chip.ts`). Заменить на генерацию ID через factory или UUID.                                                                                         |
