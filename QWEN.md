# QWEN.md — Pachisi (Парчис)

## Project Overview

**Pachisi** — это веб-реализация классической настольной игры Парчис (аналог Ludo/Parcheesi) для 4 игроков. Проект создан с использованием фреймворка [Quasar](https://quasar.dev/) (на базе Vue 3) и TypeScript.

### Ключевые особенности

- Игра для 4 игроков (красный, синий, зелёный, жёлтый)
- Пошаговая механика с броском двух кубиков
- Система безопасных ячеек, блокад и бонусов
- Поддержка ИИ-игроков (запланировано)
- Интерактивный UI с подсветкой доступных ходов

### Технологии

- **Vue 3** (Composition API, `<script setup>`)
- **Quasar Framework v2** (UI компоненты, тема)
- **TypeScript** (строгая типизация)
- **Pinia** (управление состоянием)
- **Vue Router** (маршрутизация, режим hash)
- **Vue I18n** (интернационализация)
- **Vite** (сборка)

### Игровая логика

**Состояния игры** (`GameStateEnum`):

- `START` — начало
- `SELECT_FIRST` — определение первого игрока
- `WAIT_ROLL` — ожидание броска кубиков
- `WAIT_STEP` — ожидание хода фишкой
- `WAIT_PLAYER` — ожидание перехода к следующему игроку
- `FINISH` — конец игры

**Типы досок** (`BoardType`):

- `base` — база игрока (стартовая зона)
- `main` — общая дорожка (68 ячеек)
- `home` — финишная дорожка игрока (8 ячеек)

**Ключевые правила** (реализованы в `game.ts`):

- Выход из базы только при выпадении 5
- Безопасные ячейки (отмечены в `board.ts: safes`)
- Блокады (2 фишки одного цвета на ячейке)
- Бонусы: +20 за захват, +10 за финиш
- Дубли — дополнительный ход, 3 дубля подряд — возврат фишки

## Building and Running

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
# или
quasar dev
```

Откроется браузер на локальном dev-сервере.

### Сборка для продакшена

```bash
npm run build
# или
quasar build
```

### Линтинг

```bash
npm run lint
```

### Форматирование

```bash
npm run format
```

### Проверка типов

```bash
npm run type-check
```

## Development Conventions

### Код

- **TypeScript** со строгим режимом (`strict: true`)
- **Vue 3 Composition API** с `<script setup lang="ts">`
- **ESLint** + **Prettier** для линтинга и форматирования
- Flat config для ESLint (`eslint.config.js`)

### Стейт-менеджмент

- Pinia stores с Composition API (`defineStore` с setup-функцией)
- Вычисляемые свойства через `computed()`
- Реактивные данные через `ref()`
